# API для Yatube

Проект представляет собой API для социальной сети Yatube. API позволяет работать с постами, комментариями и подписками на других пользователей.

## Описание

API предоставляет следующие возможности:
- Просмотр, создание, редактирование и удаление постов
- Работа с комментариями к постам
- Подписка на других пользователей и просмотр своих подписок
- Аутентификация с использованием JWT-токенов
